# Projet de départ du laboratoire 3

Programmation en environnement graphique, automne 2026. Unity 6000.3.11f1, URP.

Ce projet est une course à obstacles complète en deux niveaux, avec le saut, sans interface et sans personnage Mixamo. Il remplace votre laboratoire 2 comme point de départ du laboratoire 3.

Les crédits des packs importés sont dans `Assets/ImportedAssets/CREDITS.txt`.
